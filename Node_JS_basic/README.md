# Node JS Basic

This directory contains exercises for learning the basics of Node.js.

## Learning Objectives

- Run JavaScript using Node.js
- Use Node.js modules
- Read files synchronously and asynchronously
- Use the Process API
- Create HTTP servers using Node.js
- Create HTTP servers using Express
- Organize an Express application using controllers and routes

## Files

- `0-console.js` - Display a message in STDOUT
- `1-stdin.js` - Read user input from STDIN
- `2-read_file.js` - Read a CSV database synchronously
- `3-read_file_async.js` - Read a CSV database asynchronously
- `4-http.js` - Basic HTTP server using Node.js
- `5-http.js` - HTTP server displaying student information
- `6-http_express.js` - Basic HTTP server using Express
- `7-http_express.js` - Express server displaying student information
- `full_server/` - Organized Express server using controllers and routes
